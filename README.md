# Codeforces Solutions

A growing collection of competitive programming solutions for [Codeforces](https://codeforces.com) problems, written in Python.

## Structure

```
python/
├── 1030A - In Search of an Easy Problem.py
├── 110A - Nearly Lucky Number.py
├── 112A - Petya and Strings.py
└── ... (and many more)
```

Files are named `{ProblemID} - {Problem Title}.py` for easy lookup.

## How to run

Each file is self-contained. Run any solution with:

```bash
python3 "python/1030A - In Search of an Easy Problem.py"
```

Then provide input as specified in the problem statement.

## Topics Covered

- Greedy algorithms
- String manipulation
- Math / number theory
- Sorting & searching
- Implementation problems
